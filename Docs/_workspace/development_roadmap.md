# 개발 로드맵: 2D 탑다운 턴제 타일 로그라이크 1루프

## 문서 목적
- 스토리 구현보다 먼저, 2D 탑다운 턴제 타일 로그라이크의 핵심 플레이 1루프를 완성하기 위한 개발 순서를 정의한다.
- 목표 루프는 `1층 시작 -> 열린 방 탐색 -> 위험 타일 예측 -> 이동/공격/무기 선택 -> 보상 획득 -> 여러 층 진행 -> 보스전 -> 사망 또는 클리어 후 다시 1층`이다.
- 이 문서는 구현 우선순위, 단계별 완성 기준, MVP 범위, 밸런싱 기준을 정리한 작업 기준 문서로 사용한다.

## 핵심 방향

이 게임의 핵심은 액션 속도가 아니라 **턴마다 판단하는 긴장감**이다.

플레이어가 매 턴 해야 하는 핵심 고민은 다음 문장으로 요약된다.

> 저 위험 타일을 피하면서, 내가 공격할 수 있는 가장 좋은 위치는 어디지?

따라서 개발 우선순위는 아래 순서를 따른다.

1. 턴제 타일 이동
2. 위험 타일 예고
3. 적 행동 실행
4. 무기별 공격 범위
5. 타이밍 ON/OFF 추가 데미지
6. 열린 방 구조
7. 보상과 성장
8. 층 진행
9. 보스전
10. 루프 재시작

## 0단계. 1루프의 핵심 재미 정의

### 목표
- 게임의 재미를 `빠른 조작`이 아니라 `예고된 위험을 읽고 위치와 공격 수단을 선택하는 판단`으로 고정한다.
- 이후 모든 시스템이 위험 타일, 위치 선정, 무기 선택, 보상 욕심을 중심으로 작동하도록 기준을 세운다.

### 핵심 원칙
- 플레이어는 위험을 미리 볼 수 있어야 한다.
- 어떤 몬스터가 어떤 행동을 하는지는 일부 숨기되, 어떤 타일이 위험한지는 알려줘야 한다.
- 맞았을 때는 예고 없는 피격이 아니라 판단 실패로 느껴져야 한다.
- 방은 플레이어를 가두는 공간이 아니라, 위험과 보상으로 유혹하는 전술 구역이어야 한다.

### 완료 기준
- 1루프의 목표 경험을 한 문장으로 설명할 수 있다.
- 각 시스템의 우선순위가 핵심 경험과 연결된다.
- 스토리, 연출, 장기 성장보다 전투 판단 루프를 먼저 검증하기로 합의되어 있다.

## 1단계. 타일 기반 기본 조작 제작

### 목표
- 플레이어와 적이 타일 위에서 정상적으로 움직이고, 턴이 반복되는 최소 기반을 만든다.

### 구현 요소

#### 플레이어
- 상하좌우 1칸 이동
- 공격
- 무기 교체 또는 장착
- 체력
- 피격
- 사망

#### 맵
- 바닥 타일
- 벽 타일
- 장애물 타일
- 통과 가능/불가능 판정
- 방과 통로 구분

#### 기본 턴 구조

```text
현재 위험 타일 표시
-> 플레이어가 보고 판단
-> 플레이어 이동/공격
-> 적 행동 실행
-> 새로운 위험 타일 갱신
-> 다음 턴 시작
```

### 완료 기준
- 플레이어가 타일 단위로 이동할 수 있다.
- 벽과 장애물을 통과하지 못한다.
- 적도 타일 단위로 움직인다.
- 턴이 정상적으로 반복된다.

## 2단계. 적 행동 예고와 위험 타일 시스템

### 목표
- 적이 이동하거나 공격할 예정인 타일을 색으로 보여주는 핵심 시스템을 구현한다.
- 어떤 몬스터가 해당 행동을 하는지는 숨기고, 위험 위치 자체를 읽게 만든다.

### 위험 타일 구분

```text
노란색: 적이 이동할 가능성이 있는 타일
빨간색: 적의 공격이 발생할 타일
보라색: 이동과 공격 위험이 겹친 타일
진한 테두리: 여러 적의 행동이 겹친 고위험 타일
```

### 적 행동 구조
- 플레이어 쪽으로 이동
- 공격 준비
- 공격 실행
- 위치 유지
- 특수 행동

근접 몬스터 예시는 다음과 같다.

```text
플레이어가 가까움
-> 다음 턴 공격할 타일을 빨간색으로 표시
-> 플레이어 행동 후 공격 실행
```

### 완료 기준
- 적의 다음 행동 위치가 타일 색으로 표시된다.
- 플레이어는 위험 타일을 보고 피할 수 있다.
- 맞았을 때 판단 실패로 느껴진다.
- 즉발 공격, 랜덤 즉사, 예고 없는 피격은 없다.

## 3단계. 기본 전투 시스템 제작

### 목표
- 플레이어가 적을 공격하고, 적도 플레이어를 공격할 수 있는 최소 전투 루프를 만든다.

### 기본 공격

초기 무기는 가장 단순한 기본 검으로 시작한다.

```text
기본 검
공격 범위: 상하좌우 인접 1칸
피해량: 1
```

공격은 턴 하나를 사용한다.

```text
공격 선택
-> 공격 범위 표시
-> 대상 선택
-> 피해 적용
-> 적 턴 진행
```

### 피격과 사망
- 플레이어 체력이 0이 되면 사망한다.
- 사망 시 결과 화면으로 이동한다.
- 결과 확인 후 다시 1층에서 시작한다.

### 완료 기준
- 플레이어가 적을 죽일 수 있다.
- 적이 플레이어를 공격할 수 있다.
- 전투 중 이동과 공격 선택이 의미 있다.
- 죽으면 루프가 다시 시작된다.

## 4단계. 무기 시스템 제작

### 목표
- 무기를 단순 공격력 차이가 아니라, 방을 다르게 해석하게 만드는 도구로 만든다.

### 1차 무기 세트

#### 검

```text
범위: 인접 1칸
특징: 평균적인 성능
역할: 기본 무기
```

#### 단검

```text
범위: 인접 1칸
공격력: 낮음
특징: 타이밍 성공 보너스 큼
역할: 고위험 고보상
```

#### 창

```text
범위: 직선 2칸
공격력: 중간
특징: 안전거리 유지 가능
역할: 위험 타일 밖에서 공격
```

#### 도끼

```text
범위: 전방 3칸 부채꼴
공격력: 높음
특징: 여러 적 상대에 강함
역할: 방 정리용
```

#### 활

```text
범위: 긴 직선
공격력: 중간
특징: 장애물과 시야 영향 받음
역할: 멀리서 견제
```

#### 망치

```text
범위: 인접 1칸
공격력: 높음
특징: 넉백
역할: 적을 위험 타일이나 벽 쪽으로 밀기
```

### 무기 획득 방식
- 방 안에 무기 상자를 직접 배치한다.
- 플레이어는 방을 완전히 클리어하지 않아도 무기를 먹을 수 있다.
- 무기 상자는 보통 위험한 위치에 둔다.

### 완료 기준
- 무기마다 공격 범위가 다르다.
- 플레이어가 무기를 먹고 교체할 수 있다.
- 같은 방도 무기에 따라 공략법이 달라진다.

## 5단계. 타이밍 ON/OFF 시스템 제작

### 목표
- 안정적인 전투와 고위험 고보상 전투 선택지를 분리한다.

### OFF 상태

```text
공격이 즉시 처리됨
안정적
추가 데미지 없음
전투 흐름이 빠름
```

### ON 상태

```text
공격 시 짧은 리듬게임 팝업 발생
정확한 타이밍 입력 성공 시 추가 데미지
실패 시 기본 데미지만 적용하거나 약간의 페널티
```

### 초기 추천 규칙

```text
타이밍 성공: 피해량 +50%
대성공: 피해량 +100%
실패: 기본 피해량
완전 실패: 피해량 -50%
```

초기 버전에서는 실패해도 기본 피해량은 들어가게 하는 편이 좋다. 실패 페널티가 너무 크면 플레이어가 타이밍 ON을 사용하지 않게 된다.

### 무기별 확장 방향

```text
단검: 판정 좁음, 성공 보상 큼
검: 판정 보통, 보상 보통
망치: 판정 느림, 성공 시 큰 피해
활: 판정 2회 입력
창: 정확 입력 시 관통
```

### 완료 기준
- 타이밍 ON/OFF 전환이 가능하다.
- ON 상태에서 공격하면 팝업이 뜬다.
- 입력 성공/실패에 따라 피해량이 달라진다.
- ON이 항상 정답은 아니다.

## 6단계. 열린 방 시스템 제작

### 목표
- 방을 문으로 잠그는 강제 전투 공간이 아니라, 싸울지 지나갈지 보상을 노릴지 선택하게 만드는 전술 구역으로 만든다.

### 방 기본 구조

```text
통로
-> 방 입구
-> 위험 구역
-> 보상 또는 무기 위치
-> 다음 통로
```

방에 들어갔다고 전투가 강제되지는 않는다. 플레이어는 그냥 지나갈 수 있지만, 좋은 보상은 위험한 곳에 있다.

### 방 안의 선택지

```text
1. 적을 무시하고 빠르게 지나가기
2. 일부 적만 처리하고 안전하게 이동하기
3. 방을 정리하고 보상까지 챙기기
```

전투 회피를 막지 않고, 회피도 하나의 전략으로 인정한다.

### 방 상태 단계

#### 1. 감지 전
- 적이 대기하거나 순찰한다.
- 위험 타일은 적게 표시된다.

#### 2. 경계
- 플레이어가 일정 거리 안에 들어오면 적들이 반응한다.
- 위험 타일이 늘어난다.

#### 3. 교전
- 플레이어가 공격하거나 보상에 접근하면 적들이 적극적으로 움직인다.

### 완료 기준
- 방과 통로가 자연스럽게 이어진다.
- 방에 문이나 강제 전투가 없어도 플레이 흐름이 유지된다.
- 플레이어가 전투를 피할 수 있다.
- 보상을 얻으려면 위험을 감수해야 한다.

## 7단계. 방 타입 1차 제작

### 목표
- 1루프를 검증할 수 있는 최소 방 타입을 만든다.

### 방 타입

#### 1. 통과형 방
- 적이 적고 보상도 작다.
- 기본 이동, 위험 타일 읽기, 짧은 전투를 연습하게 한다.

#### 2. 보상형 방
- 중앙이나 구석에 무기, 회복, 강화가 있다.
- 보상 주변에 적과 위험 타일이 배치된다.
- 욕심낼지 말지 판단하게 한다.

#### 3. 매복형 방
- 처음엔 안전해 보이지만, 특정 타일에 접근하면 적이 활성화된다.
- 방 구조 학습과 무리한 진입 경계를 유도한다.

#### 4. 지형형 방
- 장애물, 좁은 길, 막힌 공간이 있다.
- 무기 사거리, 위치 선정, 위험 타일 회피를 활용하게 한다.

#### 5. 엘리트 방
- 강한 적이 있고 좋은 보상이 있다.
- 고위험 고보상 선택을 제공한다.

### 완료 기준
- 각 방 타입의 플레이 감각이 다르다.
- 방을 지나치는 선택과 클리어하는 선택이 모두 가능하다.
- 방마다 무기 활용도가 다르다.

## 8단계. 몬스터 1차 세트 제작

### 목표
- 위험 타일만 보고도 패턴을 점점 이해할 수 있는 기본 몬스터 세트를 만든다.

### 기본 몬스터 5종

#### 1. 추적형

```text
플레이어 방향으로 1칸 이동
가까우면 근접 공격
역할: 기본 압박
```

#### 2. 돌진형

```text
직선 방향으로 긴 이동 또는 공격
위험 타일이 길게 표시됨
역할: 위치 강제
```

#### 3. 원거리형

```text
직선 투사체 공격
장애물에 막힘
역할: 방 입구 견제
```

#### 4. 범위형

```text
주변 여러 칸을 공격
공격 전 빨간 타일 표시
역할: 좁은 공간 압박
```

#### 5. 방해형

```text
느려짐, 밀침, 위험 타일 증가 등
직접 피해는 약함
역할: 전투 변수 생성
```

### 몬스터 설계 원칙

나쁜 몬스터:

```text
예고 없이 공격함
랜덤으로 즉사시킴
피할 방법이 없음
위험 타일과 실제 공격이 다름
```

좋은 몬스터:

```text
예고가 명확함
처음엔 맞지만 다음엔 피할 수 있음
무기마다 대응법이 다름
위험 타일만 보고도 어느 정도 추측 가능함
```

### 완료 기준
- 몬스터마다 위험 타일 모양이 다르다.
- 플레이어가 여러 번 보면 패턴을 학습할 수 있다.
- 몬스터 조합에 따라 방의 난이도가 달라진다.

## 9단계. 보상과 성장 시스템

### 목표
- 전투를 피하면 안전하지만 약해지고, 전투를 하면 위험하지만 강해지는 구조를 만든다.

### 보상 종류

#### 무기
- 새 무기 획득
- 현재 무기와 교체

#### 강화
- 공격력 증가
- 체력 최대치 증가
- 타이밍 성공 피해 증가
- 특정 무기 강화

#### 회복
- 체력 회복
- 보호막 획득
- 상태 이상 제거

#### 재화
- 상점에서 사용
- 강화 제단에서 사용

### 추천 보상 배치

자동 지급보다 맵 안에 직접 배치한다.

```text
방 중앙: 무기 상자
방 구석: 회복 아이템
엘리트 뒤쪽: 강화 제단
위험 타일 사이: 희귀 보상
```

보상을 먹는 행위 자체가 전술 퍼즐이 되도록 만든다.

### 완료 기준
- 전투를 피하면 보상이 부족하다.
- 전투를 하면 강해질 기회가 생긴다.
- 보상 때문에 위험한 방에 들어갈 이유가 생긴다.

## 10단계. 층 구조 제작

### 목표
- 3개 일반 층과 1개 보스층으로 짧고 반복 가능한 1루프를 구성한다.

### 추천 층 구조

```text
1층: 기본 학습
2층: 몬스터 조합 증가
3층: 지형과 엘리트 강화
4층: 보스
```

### 한 층 구성 예시

```text
시작 지점
-> 통과형 방
-> 보상형 방
-> 지형형 방
-> 엘리트 또는 상점 선택
-> 다음 층 계단
```

문이 없기 때문에 모든 방을 클리어할 필요는 없다. 계단만 찾으면 다음 층으로 갈 수 있다. 다만 계단까지 가는 길에 보상, 위험, 몬스터 배치를 넣어 선택을 만든다.

### 완료 기준
- 층마다 여러 방이 연결되어 있다.
- 플레이어는 전투 없이 일부 방을 지나갈 수 있다.
- 계단을 통해 다음 층으로 이동한다.
- 층을 내려갈수록 위험 타일 밀도와 몬스터 조합이 어려워진다.

## 11단계. 보스전 제작

### 목표
- 보스전도 턴제 타일 판단의 종합 시험으로 만든다.

보스가 던지는 질문은 다음과 같아야 한다.

> 넓은 위험 타일 속에서 어디로 움직여야 살 수 있지?

### 보스 기본 구조

#### 1페이즈

```text
단순 근접 공격
직선 돌진
작은 범위 공격
```

목적: 보스 패턴 학습

#### 2페이즈

```text
위험 타일 조합 증가
원거리 공격 추가
안전 타일 감소
```

목적: 위치 판단 강화

#### 3페이즈

```text
연속 위험 타일
가짜 안전지대
소환 몬스터
강한 범위 공격
```

목적: 전체 시스템 종합 시험

### 보스전에서 타이밍 시스템 활용

보스는 체력이 많기 때문에 타이밍 ON을 쓰고 싶게 만들어야 한다.

```text
보스가 큰 공격 후 1턴 동안 약점 노출
이때 타이밍 ON 공격 성공 시 큰 피해
```

보스전의 이상적인 흐름은 다음과 같다.

```text
위험 타일 회피
-> 약점 턴 확인
-> 타이밍 ON 공격
-> 다시 회피
```

### 완료 기준
- 보스의 공격 범위가 위험 타일로 표시된다.
- 보스 패턴은 어렵지만 학습 가능하다.
- 무기별로 보스 대응법이 다르다.
- 타이밍 ON 공격을 쓸 명확한 순간이 있다.

## 12단계. 루프 종료와 재시작

### 목표
- 스토리 없이도 사망과 클리어 후 다시 도전할 수 있는 반복 구조를 만든다.

### 사망 시 흐름

```text
사망
-> 결과 화면
-> 다시 1층
```

표시 정보:

```text
도달 층
처치한 적 수
획득한 무기
선택한 강화
타이밍 성공 횟수
받은 피해량
플레이 시간
```

### 보스 처치 시 흐름

```text
보스 처치
-> 클리어 결과 화면
-> 다시 1층
```

표시 정보:

```text
클리어 성공
최종 무기
총 피해량
퍼펙트 타이밍 횟수
방 클리어 수
전투 회피 수
최고 기록 갱신 여부
```

첫 버전에서는 영구 성장보다 플레이어 실력 향상을 중심에 둔다.

### 완료 기준
- 죽어도 다시 시작할 수 있다.
- 보스를 잡아도 다시 시작할 수 있다.
- 결과 화면에서 플레이 기록을 확인할 수 있다.
- 다시 도전하고 싶은 이유가 생긴다.

## 13단계. 밸런싱 기준

### 목표
- 어려움보다 납득 가능함을 우선한다.
- 턴제 게임에서 억울함은 크게 느껴지므로, 모든 위험은 예고와 대응 가능성을 가져야 한다.

### 위험 타일 밀도

한 턴에 안전한 타일이 너무 적으면 불합리하다.

```text
초반: 안전 타일 60~70%
중반: 안전 타일 40~50%
후반: 안전 타일 25~40%
보스: 패턴에 따라 일시적으로 10~30%
```

### 방 통과 가능성

모든 방을 반드시 싸워야 지나갈 수 있으면 열린 구조의 의미가 사라진다.

```text
일반 방: 전투 없이 통과 가능
보상형 방: 보상을 먹으려면 전투 위험
엘리트 방: 피할 수 있지만 보상이 큼
보스 방: 강제 전투
```

### 타이밍 ON 사용률

ON을 아무도 안 쓰면 보상이 약한 것이고, ON만 쓰면 OFF의 의미가 없는 것이다.

```text
일반 적 다수: OFF가 편함
엘리트/보스: ON이 강함
위험한 상황: OFF로 빠르게 처리
큰 기회 상황: ON으로 폭딜
```
