# 퀘스트 설계 문서

## 설계 목표
- 로그라이크 반복 플레이와 서사 진행을 분리하지 않고 같은 구조로 묶는다.
- 메인 퀘스트는 던전의 진실을 단계적으로 인식하는 흐름으로 구성한다.
- 사이드 목표는 반복 플레이 중 선택 패턴, 타이밍 개입, 로그 수집, 캐릭터 해금 조건을 추적한다.
- 보상은 단순 아이템보다 `시스템 해석`, `예측 정보`, `파생 캐릭터 단서`를 중심으로 둔다.

## 진행 구조 개요

| 단계 | 구간 | 핵심 경험 | 주요 보상 |
|---|---|---|---|
| 1단계 | 진입 계단 | 기본 턴 구조와 예측 표시 이해 | 예측 UI 서사화 |
| 2단계 | 재조합 복도 | 매번 다른 듯 익숙한 던전 체감 | 기록 로그 해금 |
| 3단계 | 관측실 잔해 | 플레이어가 실험 대상임을 암시 | 로그 해석 기능 |
| 4단계 | 수렴층 | 같은 선택이 반복되고 있음을 인식 | 수렴도 표시 |
| 5단계 | 편차실 | 타이밍 개입이 시스템을 왜곡함을 확인 | 편차 기록 |
| 6단계 | 기록핵 | 반복 구조와 자기 자신을 이해 | 엔딩 및 캐릭터 해금 |

## 메인 퀘스트 라인

### MQ-01. 첫 번째 진입
- 위치: `진입 계단`
- 개요:
  - 플레이어는 던전에 들어온 탐험가처럼 시작한다.
  - 적 행동 예고가 전투 UI로 제공되지만, 초반에는 단순한 시스템 편의처럼 보인다.
- 목표:
  1. 첫 전투에서 적의 예정 행동을 확인한다.
  2. 플레이어 행동 후 적 행동이 실행되는 턴 구조를 경험한다.
  3. 첫 로그 조각을 발견한다.
- 완료 조건:
  - 첫 층을 통과하고 `기록 #001: 관측 시작` 로그 확인
- 보상:
  - 예측 표시 기능 서사적 도입
  - 기본 로그 카테고리 해금
- 핵심 문구:
  - `기록 #001: 신규 진입 개체 관측 시작.`

### MQ-02. 낯익은 배치
- 위치: `재조합 복도`
- 개요:
  - 플레이어는 다른 런 또는 다른 층에서 비슷한 방 구조와 전투 흐름을 만난다.
  - 던전이 완전한 무작위가 아니라 기록을 재조합한다는 단서가 등장한다.
- 목표:
  1. 동일한 방 형태가 변형되어 재등장하는 것을 확인한다.
  2. 반복 선택 구간을 통과한다.
  3. `동일 선택 반복` 로그를 수집한다.
- 완료 조건:
  - 재조합 방 3개 통과
- 보상:
  - 로그 필터 `반복 기록` 해금
  - 일부 방의 과거 선택 잔향 표시
- 핵심 문구:
  - `기록 #214: 동일 선택 반복. 편차 없음.`

### MQ-03. 관측실 잔해
- 위치: `관측실 잔해`
- 개요:
  - 던전 곳곳의 로그가 단순 경고문이 아니라 시스템 관측 기록임이 드러난다.
  - 플레이어는 자신이 실험 대상이라는 암시를 받는다.
- 목표:
  1. 관측 장치 3개를 조사한다.
  2. 이전 반복의 플레이어 잔향과 조우한다.
  3. 관측자 프로세스의 첫 음성을 듣는다.
- 완료 조건:
  - `예외 개체 지속 관측` 로그 획득
- 보상:
  - 로그 해석 기능
  - 이전 런 선택지 잔상 표시
- 핵심 문구:
  - `예외 개체 지속 관측. 변수 원인 미확정.`

### MQ-04. 수렴층
- 위치: `수렴층`
- 개요:
  - 플레이어가 자주 선택했던 행동이 던전 구조에 반영된다.
  - 반복 플레이에서 익숙함은 숙련이면서 동시에 고정의 징후가 된다.
- 목표:
  1. 수렴도가 높은 방을 통과한다.
  2. 이전과 다른 선택을 1회 이상 시도한다.
  3. 수렴 로그와 편차 로그를 비교한다.
- 완료 조건:
  - 수렴층 보스 `반복된 수호자` 격파
- 보상:
  - 수렴도 표시 해금
  - 파생 캐릭터 조건 일부 공개
- 핵심 문구:
  - `결과 수렴 중. 자유 행동 패턴화 진행.`

### MQ-05. 편차실
- 위치: `편차실`
- 개요:
  - 타이밍 개입이 시스템 예측을 미세하게 흔드는 유일한 변수임이 드러난다.
  - 시스템은 이 변수를 계산하려 하지만 완전히 고정하지 못한다.
- 목표:
  1. 타이밍 개입 성공 3회 달성
  2. 타이밍 실패 결과와 성공 결과를 비교
  3. 관측자 프로세스의 재분류 시도 확인
- 완료 조건:
  - `편차 유지` 로그 획득
- 보상:
  - 편차 기록 카테고리 해금
  - 보정 개체 해금 조건 공개
- 핵심 문구:
  - `편차 감지. 제거 실패. 범주화 재시도.`

### MQ-06. 기록핵
- 위치: `기록핵`
- 개요:
  - 던전의 정체, 반복되는 자신, 기록되는 모든 선택이 명확해진다.
  - 플레이어는 탈출하지 못하지만 계속 들어가기로 선택한다.
- 목표:
  1. 기록핵까지 도달
  2. 관측자 프로세스와 최종 대면
  3. 자신의 반복 기록을 확인
  4. 마지막 선택 수행
- 완료 조건:
  - 엔딩 `반복 인식` 도달
- 보상:
  - 엔딩 이후 캐릭터 해금 시스템 개방
  - 반복 기록 기반 플레이어블 캐릭터 1종 이상 해금
- 핵심 문구:
  - `기록 종료 불가. 반복 지속. 개체가 재진입을 선택함.`

## 반복 목표

| 목표 ID | 내용 | 보상 | 목적 |
|---|---|---|---|
| RQ-01 | 같은 구간에서 다른 선택 3회 수행 | 편차 로그 증가 | 선택 패턴 인식 |
| RQ-02 | 타이밍 개입 성공 10회 누적 | 보정 개체 조건 진행 | 변수의 의미 강화 |
| RQ-03 | 예측 범위 밖 피해 없이 층 클리어 | 관측 개체 조건 진행 | 예측 해석 플레이 유도 |
| RQ-04 | 빠른 턴 수로 중간 보스 격파 | 가속 개체 조건 진행 | 속도 기반 반복 축적 |
| RQ-05 | 동일 공격 행동으로 보스 처치 | 집행 개체 조건 진행 | 행동 고정의 위험 체감 |
| RQ-06 | 같은 사망 원인을 3회 반복 | 잔류 개체 조건 진행 | 실패 기록의 축적 |

## 사이드 목표

### SQ-01. 로그 #214의 원본
- 조건: MQ-02 완료 후 발생
- 목표:
  - `동일 선택 반복` 로그의 원본이 되는 과거 행동 경로를 재현한다.
  - 마지막 선택에서 일부러 다른 행동을 선택한다.
- 보상:
  - 편차 로그 1개
  - 관측자 반응 대사
- 서사 기능:
  - 플레이어가 던전 안에서 처음으로 의도적인 편차를 만든다.

### SQ-02. 삭제되지 않은 잔향
- 조건: MQ-03 완료 후 발생
- 목표:
  - 이전 반복의 플레이어 잔향 3개를 발견한다.
  - 잔향들이 서로 다른 방식으로 실패했음을 확인한다.
- 보상:
  - 파생 캐릭터 해금 단서
  - 기록 잔향 대사 추가
- 서사 기능:
  - 플레이어가 단일한 자아가 아니라 반복의 누적이라는 사실을 암시한다.

### SQ-03. 편차의 이름
- 조건: MQ-05 진행 중 발생
- 목표:
  - 타이밍 개입 성공, 실패, 미사용 결과를 각각 기록한다.
  - 관측자 프로세스가 플레이어를 재분류하는 로그를 확인한다.
- 보상:
  - 보정 개체 해금 조건 진행
  - 편차실 추가 로그
- 서사 기능:
  - 타이밍 시스템을 단순 액션 요소가 아니라 세계관 핵심 변수로 고정한다.

## 보상 설계 원칙
- 보상은 플레이어의 반복 이해도를 높여야 한다.
- 장비 보상보다 정보, 로그, 해금 조건, 예측 해석 능력을 우선한다.
- 파생 캐릭터 해금은 단순 클리어 보상이 아니라 플레이 스타일의 누적 결과로 제공한다.
- 실패도 기록으로 남아 다음 플레이의 의미를 만든다.

## 후속 대사 설계 전달 사항
- 각 메인 퀘스트마다 로그, 관측자 음성, 플레이어 독백을 배치한다.
- 대사는 과도하게 설명하지 않고 기록 문장과 짧은 반응으로 위화감을 쌓는다.
- 선택지는 선악이 아니라 `따른다`, `비튼다`, `반복한다`, `끊으려 한다`의 의도를 구분한다.
