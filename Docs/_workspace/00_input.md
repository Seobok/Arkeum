# 입력 정리

## 요청 범위
- 적용 스킬: `game-narrative`
- 작업 목적:
  - 사용자가 새로 정돈한 스토리 방향을 기준으로 기존 내러티브 문서 세트를 다시 작성한다.
  - 핵심 루프, 반복 구조, 캐릭터 확장, 턴제/예측/타이밍 시스템의 서사적 의미를 하나로 묶는다.
  - 결과물은 `_workspace/00_input.md`부터 `_workspace/05_review_report.md`까지 정리한다.

## 제목
- 가칭: `아르케움 : 기록된 선택`
- 세계명: `아르케움`
- 핵심 던전명: `아르케움`

## 장르 및 구조
- 장르: 턴 기반 로그라이크 던전 탐험
- 핵심 구조:
  - 플레이어가 먼저 행동한다.
  - 이후 이미 예정된 적의 행동이 실행된다.
  - 플레이어는 적의 이동 경로, 공격 범위, 행동 의도를 미리 볼 수 있다.
  - 특정 순간에는 타이밍 개입으로 결과를 강화하거나 왜곡할 수 있다.
  - 던전은 매 플레이마다 재구성되지만 완전한 무작위가 아니라 기록된 데이터의 재조합이다.

## 사용자 입력 요약
- 던전 `아르케움`은 단순한 미궁이 아니라 과거에 만들어진 행동 기록 및 예측 시스템이다.
- 시스템의 목적은 모든 생명체의 행동을 기록하고, 미래를 계산하며, 모든 결과를 통제 가능한 상태로 만드는 것이다.
- 시스템이 완성될수록 세계는 모든 존재가 정해진 행동만 반복하는 상태로 수렴한다.
- 던전에 들어온 존재는 점점 `기록`으로 고정된 존재가 된다.
- 주인공은 처음 던전에 들어온 탐험가가 아니라, 이미 여러 번 던전에 들어와 행동하고 기록되고 사라지고 다시 시작한 존재다.
- 현재의 플레이 역시 반복 중 하나다.
- 예측 표시는 초능력이 아니라 이미 계산된 결과의 표시다.
- 타이밍 개입은 정해진 흐름을 완전히 바꾸지는 못하지만 미세하게 왜곡할 수 있는 변수다.
- 플레이가 반복될수록 플레이어는 같은 구조, 비슷한 전투 흐름, 반복되는 선택을 통해 `이건 처음이 아니다`라는 위화감을 느낀다.
- 던전 로그는 플레이어가 실험 대상이라는 사실을 암시한다.
- 후반에는 자유조차 패턴화되고 있음을 깨닫지만, 타이밍 개입 변수 때문에 완전히 고정되지는 않는다.
- 엔딩에서 플레이어는 구조를 이해하지만 탈출하지 못한다.
- 대신 계속 들어가기로 선택한다.
- 엔딩 이후에는 이전 반복에서 파생된 존재들이 플레이어블 캐릭터로 해금된다.

## 핵심 테마
- 중심 질문:
  - `선택은 실제로 존재하는가?`
  - `모든 것은 이미 기록된 결과인가?`
- 플레이 경험:
  - 반복하면서 패턴을 이해한다.
  - 시스템을 해석한다.
  - 구조 자체를 받아들이거나 왜곡한다.
  - 클리어보다 반복의 의미를 인식하는 과정이 중요하다.

## 이번 문서에서 확정할 것
- 던전과 예측 시스템의 세계관 규칙
- 주인공과 파생 플레이어블 캐릭터의 서사적 정의
- 메인 진행 구조와 반복 플레이 목표
- 로그, 기록 잔향, 시스템 음성 중심의 대사 구조
- 분기, 플래그, 엔딩 이후 캐릭터 해금 구조

## 이번 문서에서 보류할 것
- 실제 층별 맵 레이아웃
- 보스별 상세 패턴 수치
- 전투 밸런스 수치
- UI 세부 배치
- 캐릭터별 정확한 스탯 수치

## 작업 가정
- 목표 플랫폼과 플레이 시간은 명시되지 않았으므로, 1회 런 30~60분 규모의 인디 로그라이크를 기본 가정한다.
- 던전 외부의 국가, 마을, 거대 세력은 이번 문서에서 최소화한다.
- NPC는 전통적 동료 NPC보다 `기록 잔향`, `관측 로그`, `파생 개체` 중심으로 설계한다.
- 엔딩은 완전 탈출보다 반복 구조의 인식과 이후 플레이어블 캐릭터 해금에 초점을 둔다.
