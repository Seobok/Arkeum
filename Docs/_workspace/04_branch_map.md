# 분기 구조도

## 분기 설계 원칙
- 분기는 선악 선택이 아니라 반복 구조를 대하는 태도 차이로 설계한다.
- 모든 주요 선택은 즉시 결과와 누적 결과를 모두 가진다.
- 엔딩은 완전 탈출이 아니라 반복을 어떻게 인식하고 재진입하는지에 따라 달라진다.
- 엔딩 이후 캐릭터 해금은 누적 플레이 스타일 플래그와 연결한다.

## 핵심 누적 축

| 축 ID | 이름 | 증가 조건 | 의미 |
|---|---|---|---|
| AX_CONVERGENCE | 수렴도 | 익숙한 경로, 반복 선택, 예측 일치 | 시스템에 고정되는 정도 |
| AX_DEVIATION | 편차도 | 다른 선택, 타이밍 개입 성공, 예측 경로 거부 | 시스템을 왜곡하는 정도 |
| AX_AWARENESS | 인식도 | 로그 읽기, 잔향 조사, 관측실 해석 | 반복 구조를 이해하는 정도 |
| AX_RESISTANCE | 저항도 | 관측 장치 파괴, 계산 거부, 위험한 우회 | 시스템 통제에 반발하는 정도 |
| AX_ACCEPTANCE | 수용도 | 재진입 선택, 반복의 활용, 파생 기록 인정 | 반복을 도구로 받아들이는 정도 |

| `F_REENTRY_CHOSEN` | 엔딩 선택 | 엔딩 이후 캐릭터 해금 활성화 |

| 플래그 | 조건 | 연결 해금 |
|---|---|---|
| `F_STYLE_FAST` | 낮은 턴 수 클리어 반복 | 가속 개체 |
| `F_STYLE_OBSERVANT` | 예측 표시 활용 및 로그 조사 많음 | 관측 개체 |
| `F_STYLE_PRECISE` | 타이밍 개입 성공 누적 | 보정 개체 |
| `F_STYLE_AGGRESSIVE` | 공격 선택 반복 및 처치 중심 | 집행 개체 |
| `F_STYLE_RESIDUAL` | 같은 사망/재도전 패턴 반복 | 잔류 개체 |

## 주요 분기점

### BP-01. 첫 예측을 따를 것인가
- 관련 퀘스트: `MQ-01`
- 상황:
  - 첫 전투에서 적의 예정 경로가 표시된다.
- 선택:
  1. 예정 경로를 따라 피한다.
  2. 예정 경로와 다른 칸으로 움직인다.
  3. 제자리에서 기다린다.
- 즉시 결과:
  - 1번: 안전, `AX_CONVERGENCE +1`
  - 2번: 위험하지만 새 예측 발생, `AX_DEVIATION +1`
  - 3번: 피해 가능, 기록 잔향 추가, `AX_AWARENESS +1`
- 장기 결과:
  - 초반 로그 문구와 관측자 평가가 달라진다.

### BP-02. 반복 로그를 어떻게 대할 것인가
- 관련 퀘스트: `MQ-02`
- 상황:
  - `기록 #214: 동일 선택 반복` 로그 발견
- 선택:
  1. 같은 경로를 따른다.
  2. 다른 경로를 택한다.
  3. 방을 조사해 원본 기록을 찾는다.
- 즉시 결과:
  - 1번: 빠른 진행, `AX_CONVERGENCE +2`
  - 2번: 적 배치 변형, `AX_DEVIATION +1`
  - 3번: 추가 로그 획득, `AX_AWARENESS +2`
- 장기 결과:
  - 관측 개체 해금 조건과 수렴 엔딩 조건에 반영된다.

### BP-03. 관측 장치를 부술 것인가
- 관련 퀘스트: `MQ-03`
- 상황:
  - 관측실 잔해에서 플레이어의 반복 기록이 노출된다.
- 선택:
  1. 기록을 더 읽는다.
  2. 관측 장치를 부순다.
  3. 지나간다.
- 즉시 결과:
  - 1번: `AX_AWARENESS +2`
  - 2번: `AX_RESISTANCE +2`, 일부 로그 소실
  - 3번: 진행 유지, `AX_CONVERGENCE +1`
- 장기 결과:
  - 저항 엔딩 또는 인식 엔딩 조건에 반영된다.

### BP-04. 수렴된 행동을 반복할 것인가
- 관련 퀘스트: `MQ-04`
- 상황:
  - 플레이어가 자주 쓰던 행동이 가장 효율적인 선택으로 제시된다.
- 선택:
  1. 익숙한 경로를 따른다.
  2. 불리해도 다른 경로를 택한다.
  3. 타이밍 개입을 일부러 사용하지 않는다.
- 즉시 결과:
  - 1번: `AX_CONVERGENCE +2`, 진행 안정
  - 2번: `AX_DEVIATION +2`, 난이도 상승
  - 3번: `AX_AWARENESS +1`, 관측자 특수 로그
- 장기 결과:
  - 파생 개체 해금 방향과 엔딩 톤이 달라진다.

### BP-05. 편차를 사용할 것인가
- 관련 퀘스트: `MQ-05`
- 상황:
  - 타이밍 개입으로 계산된 결과를 강화하거나 왜곡할 수 있다.
- 선택:
  1. 정확한 타이밍으로 개입한다.
  2. 일반 행동으로 처리한다.
  3. 일부러 늦게 개입한다.
- 즉시 결과:
  - 1번: `AX_DEVIATION +2`, `F_STYLE_PRECISE` 진행
  - 2번: `AX_CONVERGENCE +1`
  - 3번: `AX_AWARENESS +1`, 실패 편차 로그
- 장기 결과:
  - 보정 개체 해금과 편차 엔딩 조건에 반영된다.

### BP-06. 기록핵에서의 선택
- 관련 퀘스트: `MQ-06`
- 상황:
  - 플레이어는 반복 구조를 이해한다.
  - 탈출 경로는 없다.
- 선택:
  1. 기록을 따른다.
  2. 기록을 거부한다.
  3. 기록을 읽고 다시 들어간다.
  4. 기록을 비틀어 다시 들어간다.
- 즉시 결과:
  - 1번: 수렴 엔딩
  - 2번: 저항 엔딩
  - 3번: 인식 엔딩
  - 4번: 편차 엔딩
- 장기 결과:
  - 엔딩 이후 해금 캐릭터와 다음 런의 초기 로그가 달라진다.

## 엔딩 구조

### END-A. 수렴된 재진입
- 조건:
  - `AX_CONVERGENCE`가 가장 높음
  - `F_CORE_REACHED = true`
- 내용:
  - 플레이어는 시스템의 기록을 따른다.
  - 던전은 안정되고 다음 런은 가장 익숙한 구조로 시작된다.
  - 플레이어는 탈출하지 못하지만 가장 효율적인 반복을 얻는다.
- 감정 톤:
  - 차갑고 불안한 안정
- 해금:
  - `집행 개체` 또는 수렴 기반 변형

### END-B. 저항하는 재진입
- 조건:
  - `AX_RESISTANCE`가 가장 높음
  - 관측 장치 파괴 기록 2회 이상
- 내용:
  - 플레이어는 기록핵의 일부를 손상시킨다.
  - 던전은 더 불안정해지고 다음 런의 구조 변동 폭이 커진다.
  - 탈출은 실패하지만 시스템은 플레이어를 더 이상 안정적으로 예측하지 못한다.
- 감정 톤:
  - 거칠고 불완전한 반항
- 해금:
  - `잔류 개체`

### END-C. 인식한 재진입
- 조건:
  - `AX_AWARENESS`가 가장 높음
  - 주요 로그 70% 이상 수집
- 내용:
  - 플레이어는 반복을 끝내지 못하지만 구조를 이해한 상태로 다시 들어간다.
  - 다음 런부터 로그와 잔향 해석이 확장된다.
- 감정 톤:
  - 담담한 각성
- 해금:
  - `관측 개체`

### END-D. 편차의 재진입
- 조건:
  - `AX_DEVIATION`이 가장 높음
  - 타이밍 개입 성공 누적 조건 충족
- 내용:
  - 플레이어는 기록핵을 파괴하지 않고, 기록 사이의 틈을 남긴다.
  - 다음 런부터 일부 예측 결과가 의도적으로 흔들린다.
- 감정 톤:
  - 작지만 명확한 가능성
- 해금:
  - `보정 개체`

### END-E. 빠른 반복
- 조건:
  - 낮은 턴 수 클리어 기록 반복
  - `F_STYLE_FAST` 충족
- 내용:
  - 플레이어는 의미를 충분히 이해하지 못한 채 빠르게 반복을 통과한다.
  - 시스템은 속도 자체를 하나의 안정 기록으로 분류한다.
- 감정 톤:
  - 효율과 공허함
- 해금:
  - `가속 개체`

## 엔딩 이후 캐릭터 해금

| 해금 캐릭터 | 조건 | 다음 런 변화 |
|---|---|---|
| 가속 개체 | `F_STYLE_FAST` | 빠른 이동, 낮은 생존성, 짧은 로그 |
| 관측 개체 | `F_STYLE_OBSERVANT` 또는 END-C | 넓은 예측 범위, 더 많은 기록 표시 |
| 보정 개체 | `F_STYLE_PRECISE` 또는 END-D | 타이밍 판정 완화, 편차 로그 증가 |
| 집행 개체 | `F_STYLE_AGGRESSIVE` 또는 END-A | 공격 강화, 수렴도 빠르게 증가 |
| 잔류 개체 | `F_STYLE_RESIDUAL` 또는 END-B | 일부 실패 기록 보존, 시작 상태 불안정 |

## 분기 흐름 다이어그램

```text
MQ-01 첫 예측
  -> BP-01 예측 수용/거부/대기
  -> MQ-02 낯익은 배치
      -> BP-02 반복/변경/조사
      -> MQ-03 관측실 잔해
          -> BP-03 읽기/파괴/무시
          -> MQ-04 수렴층
              -> BP-04 반복/변경/억제
              -> MQ-05 편차실
                  -> BP-05 정확/일반/실패 편차
                  -> MQ-06 기록핵
                      -> BP-06 따른다/거부한다/읽고 재진입/비틀어 재진입
                      -> END-A/B/C/D/E
                      -> 파생 플레이어블 캐릭터 해금
```

## 리스크 및 검증 메모
- 모든 엔딩이 `탈출 실패`로 끝나므로, 플레이어가 허무하게 느끼지 않도록 해금과 다음 런 변화를 명확히 제공해야 한다.
- 분기 수치가 플레이어에게 너무 노골적으로 보이면 테마가 약해질 수 있다. UI에서는 수치보다 로그와 변화로 보여주는 방식을 권장한다.
- 파생 캐릭터는 단순 스킨이 아니라 이전 플레이 방식의 결과라는 설명이 반드시 필요하다.
